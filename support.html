FAQ

자주 묻는 질문입니다. 추가 문의는 아래 양식을 이용해 주세요.

플랫폼 점검 일정은 어디에서 확인하나요?
공지사항과 고객센터 알림을 통해 사전 안내합니다. 긴급 점검 시에는 로그인 화면 배너로도 공지합니다.
API 연동 문서는 제공되나요?
개발자 포털에서 버전별 API 레퍼런스와 샘플 코드를 제공합니다. 계약 고객은 전담 매니저를 통해 추가 기술지원이 가능합니다.
개인정보 열람·삭제는 어떻게 요청하나요?
고객지원 > 문의하기에서 ‘개인정보’ 유형을 선택하거나, 대표 메일 privacy@corp.example 로 서면 요청할 수 있습니다.
자료실에서 받은 파일이 열리지 않아요.
PDF 뷰어 최신 버전을 사용해 주시고, 동일 증상이면 파일명과 브라우저 종류를 기재해 문의해 주시면 조치해 드립니다.
